# Velora — Adult Companionship Directory

A static starter website for a legal adult companionship/directory service.

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

## Customize
- Replace the sample profiles in `script.js`.
- Change branding/text in `index.html`.
- Change design in `styles.css`.
- Connect the profile form to your own backend/API.

## Important
This is a front-end starter only. Before launch, implement jurisdiction-specific legal review, age/identity verification, moderation, privacy/security controls, reporting/blocking, payment compliance (if applicable), and appropriate terms.
